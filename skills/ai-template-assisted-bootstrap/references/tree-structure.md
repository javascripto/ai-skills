# Estrutura do Template

Saída base esperada para um template mínimo:

```text
.
├── .codex/environments
│   └── environment.toml
├── .cursor/rules
│   └── template.mdc
├── .github
│   └── copilot-instructions.md
├── .vscode
│   └── tasks.json
├── docs/ai
│   └── AGENTS.md
├── skills
│   └── README.md
├── .gitignore
├── AGENTS.md
├── CLAUDE.md
├── GEMINI.md
├── Makefile
├── README.md
└── README.pt-BR.md
```

Use esta árvore como referência antes de adicionar qualquer arquivo opcional ao template.
